        How it works. Each creature runs its own three-layer purpose network from Gomez & DeLancey, Purposeful Computation (BICA 2026): S(t+1) = 0.3·S(t) + 0.4·obs + 0.3·h, the strongest purpose wins, RESIST turns down a flagged habit’s pull by 70%, and REVISE changes weights by ±0.015. There is no controller inside. SURVIVE, FLOURISH and CONNECT are shown here as Energy, Discovery and Company.

        Adjusted for a small garden. The paper’s neighbor-count terms are replaced (in Level 1) by distance to the nearest friend, a “loneliness” state, and a “boredom” state. Each creature also has a small built-in temperament. Food, rest, thorns, mist, seasons and scoring are this game’s own rules. It is a teaching demo, not the paper’s evaluation code.

        Level 2 goes beyond the paper. Five creatures use the paper’s neighbor-count terms. Building new habits from parts (a verb like “Go to” plus targets like “Berries” and “Friend”), after repeated and tested use, is an extension made for this game. It adds structure only to the instrumental layer. The meta-purposive layer (REFLECT, RESIST, REVISE) is unchanged and treats a built habit like any other, and nothing is added on top of it. A built habit that keeps failing is dropped; that pruning rule is also part of the extension.
