Crear y editar nodos

  1. Haz clic en la herramienta Nodo en la barra izquierda (o presiona N).
  2. Haz clic en cualquier parte vacía del lienzo para crear un nodo nuevo ahí mismo.
  3. Escribe el nombre del concepto (por ejemplo perro) y presiona Enter.
  4. Para mover un nodo, cambia a la herramienta Mover (V) y arrástralo con el mouse.
  5. Para renombrar un nodo, haz doble clic sobre él.
  6. Para borrar un nodo (y todos sus enlaces), selecciónalo y presiona Supr o usa el botón Borrar.

Crear enlaces entre conceptos

Un enlace representa una relación entre dos nodos (por ejemplo, "es un", "forma parte de" o cualquier relación que tú definas). Cada enlace se convierte directamente en un hecho de Prolog.

  1. Elige la herramienta Enlace (L).
  2. Haz clic en el nodo de origen y después en el nodo de destino.
  3. En el panel derecho, elige una relación de la lista (is_a, part_of, related_to, causes, precedes, instance_of, has_property, same_as) o escribe tu propia relación personalizada en el campo de texto.
  4. También puedes elegir si la flecha es de un solo sentido o de doble sentido, el estilo de línea (sólida, discontinua, punteada) y el color.
  5. Para seleccionar un enlace ya creado, haz clic sobre la línea o su etiqueta.

El nombre de la relación se usa como el nombre del predicado en Prolog. Si escribes una relación personalizada con mayúsculas, espacios o símbolos, el programa la convertirá automáticamente en un átomo válido de Prolog (entre comillas si hace falta), sin cambiar lo que ves en el diagrama.

Construir reglas (sin escribir Prolog a mano)

Las reglas te permiten definir nuevas relaciones derivadas, como "todo lo que está bajo una categoría" o "dos elementos en la misma rama", usando solo menús y botones.

  1. Haz clic en Reglas en la barra de herramientas para abrir el constructor.
  2. Haz clic en + Nueva regla.
  3. Define la cabeza de la regla: el nombre de la nueva relación (por ejemplo bajo_categoria) y sus variables (por ejemplo X, Y).
  4. Agrega condiciones al cuerpo de la regla con el botón + Agregar condición. Cada condición puede ser una relación existente (incluida la misma regla, para crear recursión), o una comparación como X \= Y.
  5. Activa el botón \+ junto a una condición si quieres negarla (que NO se cumpla).
  6. El programa muestra abajo una vista previa en vivo del código Prolog que se va a generar.

Ejemplo: una regla con cabeza under(X, Y) y dos condiciones alternativas (is_a(X, Y), y is_a(X, Z) seguido de under(Z, Y) de forma recursiva) genera exactamente el patrón de "todo lo que está debajo de una categoría" usado en clase.

Exportar e importar tu trabajo

  • JSON: guarda toda tu red (nodos, enlaces y reglas) en un archivo .json que puedes volver a abrir después con el botón Importar, o compartir con tu profesor.
  • Imagen (PNG): descarga tu red tal como se ve en el lienzo, lista para pegar en un documento o presentación.
  • Enviar a Prolog: convierte tu red y tus reglas en código Prolog real y lo abre automáticamente en el Editor Prolog, como un archivo nuevo.

El Editor Prolog

Funciona de forma parecida a SWISH: un editor de código a la izquierda/arriba y una consola de consultas abajo. Todo se ejecuta dentro de tu navegador, no necesitas instalar nada.

  • Nuevo archivo: abre una pestaña en blanco.
  • Abrir / Importar: carga un archivo .pl desde tu computadora.
  • Exportar: descarga el contenido actual del editor como un archivo .pl.
  • Consultar programa: carga (consulta) tu código en el motor de Prolog, para poder hacer preguntas sobre él.
  • Puedes tener varios archivos abiertos a la vez; aparecen en la lista de la izquierda.

Escribir y ejecutar consultas

  1. Primero presiona Consultar programa para cargar tu código.
  2. Escribe una pregunta en la barra ?-, por ejemplo is_a(violin, bowed), y presiona Ejecutar o Enter.
  3. Si la consulta tiene variables (por ejemplo is_a(X, bowed)), verás el valor encontrado para cada variable.
  4. Si hay más de una respuesta posible, aparecerá un botón Siguiente solución ; para pedir la próxima, igual que escribir ; en Prolog normal.
  5. Si la consulta es simplemente verdadera o falsa (sin variables), verás true. o false.

Atajos de teclado (Diseñador de Redes)

  • N — herramienta Nodo
  • L — herramienta Enlace
  • Espacio (mantener) — desplazar el lienzo temporalmente
  • Supr / Backspace — borrar lo seleccionado
  • Ctrl+Z — deshacer
  • Ctrl+Y — rehacer
  • Rueda del mouse — acercar / alejar
